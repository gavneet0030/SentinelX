# SentinelX

## Real-Time Explainable Risk & Anomaly Intelligence Platform

SentinelX is a production-oriented risk intelligence platform combining:

- Transaction intelligence
- Behavioral analysis
- Temporal analysis
- Graph intelligence
- Supervised machine learning
- Anomaly detection
- Rule-based detection
- Explainability
- Real-time event processing
- Risk scoring
- Decisioning
- Human review
- Model monitoring
- MLOps
- Observability
- Cloud deployment
